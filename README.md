# Mh-MCMC
Metropolis-Hastings MCMC implementation for finance

This small first project was based off of a randomly sampled MH-MCMC that I did a code-along in a class in my first sophomore semester at RPI. 
I was inspired to push my learning further and apply this method to an area I'm interested in, that being financial markets.

This particular implementation calculates priors independently, so next I will create a relatively similar implementation but with a joint prior.


For my newly uploaded joint prior MH-MCMC I choose to use a multivariate normal distribution and arbitrarily chosen first states and prior means.

I am still in the learning process for this and will continue to update this repo and add more and more MCMC algorithms as I become more advanced and understand it better.
